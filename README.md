## 🚀 SOBRE O PROJETO

O **MOTTA PC FIX** é uma ferramenta desenvolvida para facilitar a manutenção e o diagnóstico de computadores com Windows.

O programa reúne diversas funções em uma única interface, permitindo realizar **limpeza de arquivos temporários**, **reparo de componentes do Windows**, **reparo de rede**, **teste de velocidade da internet**, **benchmark de desempenho** e uma **avaliação geral do computador**.

Tudo isso através de uma interface simples, moderna e fácil de utilizar.

---

# ✨ PRINCIPAIS RECURSOS

## 🧹 LIMPEZA PROFUNDA

Realiza a limpeza de arquivos temporários e dados desnecessários do sistema.

Inclui:

* 🗑️ Limpeza de arquivos temporários do usuário
* 🗑️ Limpeza da pasta temporária do Windows
* 🌐 Limpeza do cache DNS
* ♻️ Esvaziamento da Lixeira
* 📊 Contagem de arquivos removidos
* 💾 Cálculo do espaço liberado

---

## 🛠️ REPARO DO WINDOWS

Executa ferramentas nativas do Windows para verificar e reparar arquivos do sistema.

### DISM

* `DISM /Online /Cleanup-Image /CheckHealth`
* `DISM /Online /Cleanup-Image /ScanHealth`
* `DISM /Online /Cleanup-Image /RestoreHealth`

### SFC

* `sfc /scannow`

Essas ferramentas ajudam a identificar e reparar possíveis problemas nos arquivos do Windows.

---

## 🌐 REPARO COMPLETO DE REDE

Executa uma sequência de comandos para tentar corrigir problemas de conexão.

Inclui:

* Limpeza do DNS
* Reset do Winsock
* Reset do TCP/IP
* Reset IPv4
* Reset IPv6
* Renovação do endereço IP

⚠️ Após o reparo de rede, pode ser necessário reiniciar o computador.

---

# 📡 TESTE DE INTERNET

O MOTTA PC FIX realiza um teste de conexão utilizando servidores da Cloudflare.

O teste verifica:

* 📶 Ping
* 📦 Perda de pacotes
* 🌐 DNS
* 📥 Velocidade de Download
* 📤 Velocidade de Upload
* 📍 Localização aproximada do servidor utilizado

Os resultados são exibidos diretamente na interface do programa.

---

# 📊 AVALIAÇÃO DO COMPUTADOR

O programa utiliza o **WinSAT**, ferramenta nativa do Windows, para realizar uma avaliação de desempenho do computador.

São analisados:

| Componente | Avaliação          |
| ---------- | ------------------ |
| 🧠 CPU     | Processador        |
| 🎮 GPU     | Desempenho gráfico |
| 🧠 RAM     | Memória            |
| 💾 Disco   | SSD / NVMe / HDD   |

Após a análise, o MOTTA PC FIX gera:

## ⭐ NOTA GERAL

Uma avaliação geral de **0 a 10**, baseada nos resultados dos principais componentes.

---

🟢 **MUITO BOM**

🔵 **EXCELENTE**

# ⚠️ AVISO

O MOTTA PC FIX utiliza ferramentas e comandos nativos do Windows para realizar diagnósticos, reparos e manutenção.

Algumas operações podem:

* Redefinir configurações de rede

* Demorar vários minutos
* Solicitar reinicialização do computador

Recomenda-se fechar programas importantes antes de iniciar uma **Manutenção Completa**.
